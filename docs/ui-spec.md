# UI specification

The written companion to the Figma design (see `PLAN.md` §3.4). The Figma file says how Kubelook looks; this file holds
the rules a picture does not show and the links to every frame. `docs/spec.md` says what the product does.

This file is filled in step by step during Stage 2 of `PLAN.md`.

## The Figma file

- File: [Kubelook](https://www.figma.com/design/7GL9OClDE6owIsAmPUDM55) (file key `7GL9OClDE6owIsAmPUDM55`), in the
  owner's personal Figma account (Starter plan), one shared file for the whole product (D8a).
- **Pages.** The Starter plan limits a file to 3 pages, so the layout of `PLAN.md` U2.0 is folded into sections:

  | Page | Holds |
  | --- | --- |
  | Foundations | Variables (colour, spacing, radius, type; light and dark modes), text styles, icons |
  | Components | The Mantine kit of D8b and the Kubelook components with their states (U2.3) |
  | Screens | Three sections: **Shell** (U2.2), **Screens** (U2.4, one frame per screen and state, 1440×900, both themes), **Flows** (U2.5, prototype flows for the §6 walkthrough) |

- **Write access.** Checked on 2026-11-26: the agent creates and removes nodes in the file through the Figma MCP tools,
  although `whoami` lists the account's seat as `View`.
